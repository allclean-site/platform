# Документы по защите персональных данных — «ALL CLEAN COMPANY» SRL

Комплект под **Закон Республики Молдова № 195/2024** о защите персональных данных
(опубликован 23.08.2024, **в силе с 23 августа 2026**; до этого действовал закон
№ 133/2011). Это полный перенос европейского GDPR в молдавское право: те же
основания обработки, те же права людей, та же логика штрафов —
**до 1 000 000 леев или 1 % годового оборота**, за серьёзные нарушения —
**до 2 000 000 леев или 2 %**, применяется бо́льшая величина.

Документы написаны по тому, что сайт и работа с заявками делают **на самом деле**.
Это не придирка к формулировкам: закон прямо требует, чтобы реестр и политика
описывали реальные процессы. Скачанный из интернета шаблон при проверке
работает против вас — он доказывает, что процессы никто не разбирал.

| Файл | Что это | Кому показывают |
|---|---|---|
| [`ropa.md`](ropa.md) | Реестр деятельности по обработке — таблица процессов | инспектору CNPDCP по официальному запросу |
| [`incidents.md`](incidents.md) | Что делать при утечке, уведомление за 72 часа | внутренний; шаблон письма — в CNPDCP |

| [`dpa.md`](dpa.md) | Договоры обработки с поставщиками: у кого как подписывается | внутренний |

## Где что лежит

Сайт allclean.md публикуется **этим репозиторием**, а не исходным Astro-проектом
(`allclean-site/site` — теперь архив). `scripts/build-site.mjs` собирает страницы
из зеркала `public/import/allclean` и правок редактора, поэтому все изменения по
защите данных живут в сборщике:

| Файл | Что делает |
|---|---|
| `scripts/site-privacy.mjs` | правки поверх зеркала: свой домен вместо чужого CDN, обязательная галочка согласия и его запись, закрытые фотографии, реквизиты в подвале. Там же `POLICY_VERSION` |
| `scripts/legal-pages.mjs` | тексты политики и страницы cookie на RO и RU; из них собираются `/privacy`, `/ru/privacy`, `/cookies`, `/ru/cookies` |
| `scripts/localize-cdn.mjs` | втягивает на свой домен картинки, которые редактор подставляет с чужого CDN |
| `scripts/supabase-consent.sql` | столбцы доказательства согласия |
| `scripts/supabase-photos-private.sql` | закрытие хранилища фотографий |
| `vercel.json` | заголовки безопасности |
| `api/leads.js` | подписывает ссылки на фотографии для панели |

Сборка не выпустит сайт без обязательных правок: `assertApplied()` в
`site-privacy.mjs` роняет её, если зеркало изменилось и якорь не совпал.

## Главное правило сопровождения

**Появился новый способ собирать данные или новое место, где они лежат — в тот же
день строка в реестре и абзац в политике.** Новая форма, счётчик, чат, карта,
виджет обратного звонка, CRM, рассылка — каждое из этого меняет оба документа.
Политика, отставшая от сайта, хуже отсутствующей: она документирует нарушение.

Если меняется текст политики — меняется и `POLICY_VERSION` в `src/lib/legal.ts`.
Эта строка уходит в базу вместе с каждой заявкой; по ней видно, на какую именно
редакцию соглашался человек. Без неё отметка о согласии ничего не доказывает.

## Проверка сайта одной командой

Поведение сайта проверяется не глазами, а сканером из репозитория агентства:

```bash
python tools/privacy_scan.py https://allclean.md --pages / /book-cleaning /calc/general-cleaning /privacy
```

Он показывает сторонние домены, cookie до согласия, записи в памяти браузера,
разметку форм (есть ли обязательная неотмеченная галочка), ссылку на политику и
заголовки безопасности. Результат последнего прогона — в [`checklist.md`](checklist.md).

## Оговорка

Составлено инженером, не юристом. При штрафах до 2 000 000 леев эти документы
стоит показать юристу — они написаны так, чтобы ему осталось проверить, а не
писать с нуля. Для проверки CNPDCP внутренние документы, скорее всего,
понадобятся на румынском; публичная часть на сайте уже двуязычна.
